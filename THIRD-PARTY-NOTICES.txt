BreakTime Companion Module - Third-Party Notices

This module includes third-party software, redistributed under the terms of the respective
licenses. The components below are the runtime dependency tree the build takes inventory
of, plus code that two of those packages carry inside them. Not every listed package ends
up in the bundled code. Full license texts are provided in the licenses/ folder.

Development tools (eslint, prettier, @companion-module/tools and the packages they bring in)
are used only to build and check the module. They do not ship and are not listed.

----------------------------------------
Companion module framework (Bitfocus)
----------------------------------------

@companion-module/base is the Bitfocus framework the module is built on. It brings in these
packages: ajv (with fast-deep-equal, fast-uri, json-schema-traverse and
require-from-string), colord, ejson, eventemitter3 5.0.1, mimic-fn, nanoid, p-queue (with
its own eventemitter3 4.0.7 and p-timeout 3.2.0, which brings p-finally), p-timeout 4.1.0
and tslib. All are MIT-licensed except fast-uri (BSD-3-Clause) and tslib (0BSD).

@companion-module/base also carries a modified copy of debounce-fn 4.0.0 (MIT) in its
lib/debounce-fn folder, which is built into the module. Its license text is in
licenses/debounce-fn.txt.

ejson's index.js is a prebuilt bundle of Meteor's EJSON and Base64 code (MIT), which is
built into the module. ejson's build took that code from Meteor's devel branch, not from a
release, so it has no version. Its license text is Meteor's LICENSE file, unchanged since
2020, in licenses/Meteor.txt.

Each package's license text is in licenses/<package name>.txt, and the text for
@companion-module/base is in licenses/companion-module-base.txt. Both eventemitter3 versions
have the same license text, in licenses/eventemitter3.txt. The two p-timeout versions have
different texts, in licenses/p-timeout-3.2.0.txt and licenses/p-timeout-4.1.0.txt.

The @companion-module/base 1.13.6 package has no license file, and neither does its v1.13.6
tag. Its text is the LICENSE file Bitfocus later added to the same repository, first tagged
in companion-module-base-v2.2.0.

WebSocket client (ws)
----------------------------------------

ws is the WebSocket client the module uses for BreakTime's live state feed. It has no
dependencies of its own. Its optional native add-ons (bufferutil and utf-8-validate) are not
installed and do not ship. MIT-licensed; its text is in licenses/ws.txt.
