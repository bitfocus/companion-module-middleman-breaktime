BreakTime Companion Module - Third-Party Notices

This module includes third-party software, redistributed under the terms of the respective
licenses. The components below are the runtime dependency tree the build takes inventory
of. Not every listed package ends up in the bundled code. Full license texts are provided
in the licenses/ folder.

Development tools (eslint, prettier, typescript, @companion-module/tools and the packages
they bring in) are used only to build and check the module. They do not ship and are not
listed.

----------------------------------------
Companion module framework (Bitfocus)
----------------------------------------

@companion-module/base is the Bitfocus framework the module is built on. As of 2.2.2 it
brings in just two packages, both MIT-licensed: colord and zod. colord's code is bundled
into the module. zod is a declared dependency of @companion-module/base, but the parts of
the framework the module imports do not pull it into the bundle; it is listed here because
it is part of the installed runtime dependency tree.

@companion-module/base ships its own MIT LICENSE file, whose text is in
licenses/companion-module-base.txt. The colord and zod license texts are in
licenses/colord.txt and licenses/zod.txt.

WebSocket client (ws)
----------------------------------------

ws is the WebSocket client the module uses for BreakTime's live state feed. It has no
dependencies of its own. Its optional native add-ons (bufferutil and utf-8-validate) are not
installed and do not ship. MIT-licensed; its text is in licenses/ws.txt.
